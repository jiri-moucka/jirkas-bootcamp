# Shell Scripting 

- shell - program that interprets commands to kernel
 - sh: /bin/sh
 - Bash: /bin/bash Improved of sh - is used in Linux
   - is shell script
All shell scripts have the same _.sh_ file extension
-> we have to tell to the OS which to use.
   - #!/bin/sh
   - #!/bin/bash
   - #!/bin/zsh

#! - is shebank (shortage)
.sh - is always installed in unix OS

## run script
use `./scriptname.sh`
or `bash scriptname.sh`
